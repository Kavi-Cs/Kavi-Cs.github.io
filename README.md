# Kaveesha Induwara — Engineering Portfolio & Interactive CV

Modern, production-grade developer & hardware-AI engineering portfolio built with **Next.js 15 (App Router)**, **TypeScript**, and **Tailwind CSS v4**.

## Live Deployment on GitHub Pages (2026 CI/CD Workflow)
1. Create a public GitHub repository named `Kavi-Cs.github.io` (or any repository name).
2. Push all files in this folder to the `main` branch.
3. Go to **Settings → Pages → Build and deployment → Source** and select **GitHub Actions**.
4. GitHub Actions will automatically build and publish your live site at `https://kavi-cs.github.io/`.

## How to Add / Edit Projects Permanently
Open `src/data/portfolio.ts` and edit the `DEFAULT_PROJECTS` array. Adding a new project there automatically updates both the **Projects Showcase** and the **Pro Executive CV PDF**.
